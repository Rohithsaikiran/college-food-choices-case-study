College Food Choices Case Study
About the Project
The College Food Choices Case Study is a data analytics project focused on understanding food preferences and eating habits among college students. The project explores food-related data to identify patterns, compare preferences, and generate meaningful insights through data analysis and visualization.
Objectives

- Analyze food preferences among college students.
- Understand students' eating habits and food choices.
- Explore trends and patterns in the available dataset.
- Present data in a clear and understandable format.
- Generate insights to support better understanding of student food preferences.

Tools and Technologies

- Tableau
- Microsoft Excel / CSV (if applicable)
- Data Analytics
- Data Visualization

Project Workflow

1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Data Visualization
5. Interpretation of Results

Key Analysis Areas

- Food preferences of college students
- Eating habits and food consumption patterns
- Comparison of food choices across relevant categories
- Trends and patterns in the dataset

Key Learnings

- Understanding the data analytics workflow
- Preparing data for analysis
- Exploring datasets to identify patterns
- Creating visualizations to communicate information
- Presenting analytical insights clearly
